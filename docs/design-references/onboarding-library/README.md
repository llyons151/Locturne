# Onboarding library

Collected 2026-10-05 from ScreensDesign (screensdesign.com). Each folder has FLOW.md, the full
recorded session screen by screen (timestamps plus a text description of every screen), and the
images ScreensDesign shows for free: `001–008.jpg` (the first 8 screens, in order) and
`showcase-N.jpg` (unordered). Screens past the first 8 are text-only: the images are on
ScreensDesign's paid plan and weren't downloaded. Revenue figures are ScreensDesign estimates.

`_locturne-before/` has Locturne's own onboarding (web preview, 4 screens per image, in step
order). `_analysis/` has the per-group teardowns. The synthesis is
[docs/ONBOARDING_10.md](../../ONBOARDING_10.md).
