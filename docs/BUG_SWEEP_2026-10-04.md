## Fixed

**Revenue and billing copy**
1. **A cancelled trial still said "Then the annual plan starts".**
   - **What happened:** the stored trial end was only cleared by onboarding's "Remind me".
     Someone who cancelled in Apple's sheet kept Home's notice, the You tab's trial row and
     the 2-day reminder, which all promised a charge that would never come.
   - **Fix:** `EntitlementRecord` now keeps `willRenew: false`. `currentTrialEnd()` returns
     null for a trial that won't renew.
   - **Where it runs:** on every launch and return to the app, `useAppStart` calls
     `syncTrialEnd` (`lib/notifications.ts`).
     - It drops the end and the reminder when the trial has stopped renewing or has ended.
     - If auto-renew is turned back on and "Remind me" was chosen, it brings them back.
     - It only runs after the store or the cache has answered.
   - **Note:** a downgrade to monthly during the trial can't be seen. iOS applies it at
     renewal, so the entitlement still reads annual.
   - **Tests:** `revenuecat.test.ts` and `notifications.ios.test.ts`.
2. **"Your free week ends…" on a 14-day trial.** The billing line and its row label said "free week" even when the longer-trial exit offer was bought. They now say "free trial".

**Morning wake-up**

3. **The downstairs "Stop" button left the screen stuck.**
   - **What happened:** `stop()` stopped listening but left the session in place. Stop stayed on screen and did nothing, Start never came back, and the timeout clock had stopped too.

4. **The morning shield said "scan your code" when no code was set up.**
   - **What happened:** Home and the wake screen fall back to steps in that case, but the shield didn't.
   - **Fix:** the new `lib/scan-code.ts` `methodInUse()` is shared by the shield text and Home. Saving a code now syncs, so the shield switches to "scan" straight away.
   - **Why a new file:** `scan.ts` imports the lock controller, and this avoids a cycle.
   - **Test:** `lock-controller.test.ts`. It fails on the old code.
5. **`/wake` sent scan users to code setup outside the morning.**
   - **What happened:** a scan user who tapped a notification at night got "set up or change your code" instead of "Still bedtime".
